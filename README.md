# TV Guard（开发中）

面向 **斐讯 N1 / LEDE R26.11.3 / FW3 + iptables-legacy** 的中文电视使用时间管理插件。

当前仓库刚建立；功能将在开发分支通过代码审查后逐步合入。**尚无可直接安装的稳定版本**。

## 设计目标

- 儿童、家长、手动锁定模式；工作日/周末不同额度
- 奖励 +15 / +30 / +60 分钟及可追溯日志
- 智能平衡：可靠识别空闲时不计时；无法确定时仍计时
- 对 OpenWrt 旁路由 SSR 透明代理路径进行防火墙适配
- 默认 **只观察、不自动封禁**；开启控制需要明确操作
- 兼容 LuCI 中文管理界面，便于在手机操作

## 关键限制

路由器无法直接知道电视显示的前台界面。网络包数（PPS）不能证明电视处于“系统首页”“App 首页”或“视频暂停”；这些状态必须先经过实测校准并验证才允许自动免计时。旁路由也无法阻止电视绕过 N1 直连主路由。

技术方案和开发记录见后续提交。
