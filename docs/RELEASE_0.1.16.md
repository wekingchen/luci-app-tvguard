## r19 · LuCI 深色模式可读性修复

- 用户 2026-11-18 iPhone Chrome 截图显示 LuCI 家长设备配对页面配对码文字与深色背景严重混淆，说明文字偏暗，标题被渲染为大块深灰背景。属于浏览器内 LuCI 页面问题，与独立家长遥控 Web App 不同。

- 卡片标题改用带 `role=heading` 的 div，避开 LuCI 主题对原生 h3 的背景与内边距规则；保留语义可访问性。
- 两页均升级样式缓存键至 `?v=0.1.16-r19`。CI 增加高对比度及安装包内容检查，避免只更新源码而打包/加载旧 CSS。
- 不涉及正式控制、计时、配对授权、Agent、Bark 或 Tunnel Token。**本次修复尚待实际 iPhone 深色模式验收，自动化通过不等于像素级验证。**

## 使用方式

1. 基线 r16 已由用户完成多项真机验收；升级 r17 只需 N1 主 IPK，不需要更新已安装的同版电视 Agent。
2. iPhone 已通过 Safari 添加 `https://tv.rqqr.de/` 至主屏幕，并提交 r17 真实界面截图；标题状态栏遮挡已修复。
3. 家里和外面均使用同一公网域名，可避免快捷指令和分流 DNS；如有需要，可保留局域网 HTTP 作为备用。
4. 已配对授权默认长期有效，清除浏览器 Cookie/无痕模式仍可能导致重配；LuCI 可单台撤销或撤销全部。
5. 当前不启用 Cloudflare Access。外网配对页面可被公众打开，**控制操作必须通过 TVGuard 配对授权**；禁止公开 LuCI/RPCD/SSH/Docker Socket。
