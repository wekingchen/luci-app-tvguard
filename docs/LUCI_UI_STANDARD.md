# TVGuard · LuCI 四页统一视觉规范（r20）

## 唯一基准：概览

`htdocs/luci-static/resources/view/tvguard/overview.js` 的 `responsiveStyles()` 是视觉基准。本轮不改变其已验收的布局，后续改动必须对照概览并同步检查其余页面。

| 项目 | 统一规则 |
| --- | --- |
| 页面容器 | 最大宽度 980px，水平居中；桌面与手机遵循原生 LuCI 主题文字色 |
| 页面标题 | 1.45rem / 700，手机 1.28rem；“TV Guard · 页面名”，下接一行功能说明 |
| 主卡片 | 透明背景、1px `rgba(127,127,127,.42)` 细边、12px 圆角、15px 内边距、14px 间距；手机 10px 圆角、12px 内边距 |
| 统计块 | 灰阶 8% 透明背景、32% 边框、10px 圆角；字体 1.13rem，说明文字次级 |
| 操作按钮 | LuCI 原生 `btn cbi-button-action / positive / negative`，高 ≥36px、按钮组间距 8px，保证概览与其他页一致 |
| 展开区 | 细分隔线、紧凑说明，技术诊断默认折叠 |
| 响应式 | 700px 以下单栏卡片、统计双列；窄屏下操作按钮不会溢出 |
| 深色模式 | 卡片不强制填充蓝黑色，继承 LuCI 主题；说明文字足够亮；一次性配对码继续使用 r19 的高对比度文字 |
| 设置 | 继续使用原生 `form.Map` / UCI 保存与验证，只加一致的视觉外壳与样式，不改字段或回调 |

## 四个页面

- **概览**：设计源，不调整计时卡片、模式按钮或学习中心逻辑。
- **设置**：保留工作日/周末额度、时段、静默判断、Bark 和设备绑定等原生表单，只统一外框、页面标题与说明、字段间距。
- **家长遥控**：保留服务状态、内网直连、配对码和设备授权的所有功能，卡片与按钮改成概览风格。
- **远程访问**：保留 Tunnel、Token、Metrics、诊断与日志，采用相同的页面标题、统计块和面板结构。

## 实施与安全边界

- 不修改`/usr/libexec/tvguard*`、Agent、核心算法、iptables/RAW、Bark 发送、Token 存储、授权 Cookie 或 Cloudflare Tunnel 回源逻辑。
- 页面样式采用 `panel.css?v=0.1.16-r20`，在三个非概览页面共用；概览维持已验收的内嵌基准样式。
- 新增四页视觉契约测试、设置表单回归、家长设备操作回归、深色对比度测试、IPK 实物检查。
- 静态测试与模拟 DOM 不能替代 LuCI 真机像素级验收；发布后仍需用 Chrome/Safari 检查 iPhone 深色和浅色模式，以及桌面浏览器。
