# TVGuard · iPhone 单一桌面入口

## 项目状态与原则

本指南基于已在 N1 + iPhone 验收的 TVGuard v0.1.16-r16：
- 家中直连：`http://192.168.101.99:18765/`
- 外网 HTTPS：`https://tv.rqqr.de/`（已配置 TVGuard 专用 Cloudflare Tunnel）
- **不启用 Cloudflare Access**；家长控制仍由 TVGuard 一次性配对会话保护。
- LuCI「家长遥控」和「远程访问」桌面及手机 UI 已于 2026-11-18 通过用户实际验收。

优先不为 iPhone 桌面图标修改 TVGuard 内核、路由、Docker、代理或 Cookie 协议。

## A. 可选：快捷指令选择家中/外网

在 iPhone 的「快捷指令」App 中新建快捷指令，命名为「TVGuard 家长遥控」：

1. 添加操作「获取网络详细信息」（Get Network Details），网络选择 **Wi-Fi**，详细信息选择 **IP 地址**。
2. 添加「如果」（If）。条件为：刚才取得的 Wi-Fi IP 地址 **开头是** `192.168.101.`。若系统只提供「包含」，则使用「包含 `192.168.101.`」。
3. 在「如果」分支内，添加「URL」，填 `http://192.168.101.99:18765/`，再添加「打开 URL」。
4. 在「否则」分支内，添加「URL」，填 `https://tv.rqqr.de/`，再添加「打开 URL」。
5. 结束「如果」，运行测试。在快捷指令的详情中选择「添加到主屏幕」，命名「TVGuard」，选定自己喜欢的图标。

**判断依据**：当前家庭 N1/电视 IP 在 `192.168.101.x`，快捷指令以手机当前 Wi-Fi IP 是否处于同一 /24 网段作轻量判断。此方式不需要知道 Wi-Fi SSID，也无需向公共服务上传本地 Wi-Fi 信息。

**局限**：其他 Wi-Fi 恰好也使用 `192.168.101.x` 时可能误判为家中；家庭 DHCP 网段变更时可能转而走公网。需要更严格判断时，把「如果」条件改成当前 Wi-Fi **网络名称与家庭 SSID 完全匹配**，但需要用户自己在快捷指令中填入准确 SSID，并留意 iOS 读取网络名的隐私授权。快捷指令本身没有真正的自动重试/错误恢复，不能承诺本地地址不可达时会自动重新打开公网链接。

iPhone 的「打开 URL」会交由系统浏览器处理，并非把两个不同 Origin 合并成一个独立 PWA 容器。家庭 HTTP 和外网 HTTPS 的 Cookie 独立，首次可能各配对一次；Safari/Chrome 普通模式应优先于无痕模式。打开浏览器选项卡不等同于 iOS 全屏 Web App。

## B. 推荐：一个原生全屏 Web App 图标

当前已确认家中和外网均可通过 Cloudflare Tunnel 正常使用，因此**优先推荐此方案**：在 **Safari** 打开 `https://tv.rqqr.de/`，分享 →「添加到主屏幕」，启用「作为 Web App 打开」（具体文案以 iOS 系统为准）。

此方式同一个 HTTPS 入口可同时在家中与外面使用，不需要判断 Wi-Fi、也不需要快捷指令；体验更接近独立 App。代价是家中也会通过 Cloudflare Tunnel。首次从主屏 Web App 打开时可能需要重新配对（Web App 和 Safari 页面可能拥有不同 Cookie 容器）。

**两种方案不要同时在主屏放两个同名图标**。本次稳定版默认推荐 B；只有明确需要家中不经 Cloudflare 时才选择 A。

## iPhone 真机验收

1. 家中 Wi-Fi：点唯一图标，正常进入家长遥控；选择 B 时顶部显示「Cloudflare Tunnel · 在线」，选择 A 时显示「内网直连 · 在线」。
2. 关闭 Wi-Fi、启用蜂窝网络：同一图标再次打开；若选择 A，顶部显示「Cloudflare Tunnel · 在线」。
3. 从普通浏览器退出再进入，不应每次要求配对；跨 Origin 首次要求分别配对属正常。
4. 测试无痕模式或删除 Cookie 后提示重新配对，避免把 Cookie 丢失误当成服务异常。
5. 模式切换 / 时间奖励只执行一次，出现超时应先刷新状态，不能连续重复加时。
6. 两条网络均只进入家长遥控，不应出现 LuCI、RPCD、SSH 或 Docker 管理页面。

以上属于用户端手动创建和真机验收步骤；项目本身不包含可直接导入 iOS 的已签名快捷指令，不能以未验证的 `.shortcut` 文件替代 Apple 的正式安装流程。
